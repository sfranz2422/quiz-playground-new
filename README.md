# QuizPlayground


Quiz Playground (https://quizplayground.replit.app/)
As Lead Web Developer, I built Quiz Playground, a backend-heavy site using Flask for dynamic assessments. I developed AI-powered question generation, user authentication, and real-time data processing. Designed an optimized database, integrated APIs, and implemented caching for performance. Managed deployment, security, and scalability to support high user engagement. This project highlights my expertise in Flask, backend development, and AI-driven web apps.
